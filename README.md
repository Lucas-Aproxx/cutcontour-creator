# Cut Path Creator

Maak een software waar ik bestanden kan uploaden, aangeven waar ik een cutcontour wil hebben, ik moet er zoveel als ik wil kunnen toevoeggen. Hieronder vind je uitleg hoe een cutcontour altijd moet gemaakt worden. en in het bestand in bijlage. Zorg ook altijd dat ik het pdf dat ik upload altijd kan downloaden volgens afdruknorm CMYK.

Snijlijnen in aparte laag met naam "Cutcontour":

Bij ontwerpen die in contour dienen gesneden te worden raden we aan om de snijlijn in een andere laag dan het ontwerp te plaatsen. Deze laag noemt u dan "Cutcontour''. Indien u niet zeker bent, kiest u bij "aanleveren printbestand" voor "controleer mijn bestand". Wij controleren dan of uw snijlijn correct staat.
